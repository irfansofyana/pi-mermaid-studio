# C4 diagrams

Pinned documentation baseline: Mermaid 11.16.1
Official source: https://mermaid.js.org/syntax/c4.html

Mermaid C4 syntax is experimental. Use it only when C4 abstraction discipline is the point.

Keep exactly one level per diagram: context, container, component, or deployment. Use concise technology/responsibility descriptions and directional relationships. Do not mix containers and implementation classes, or use C4 as a generic architecture decoration. Prefer architecture diagrams when experimental syntax is an unnecessary risk.
